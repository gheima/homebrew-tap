# Homebrew tap for Gheima

```bash
brew install gheima/tap/gheima
gheima --version
```

`Formula/gheima.rb` installs the standalone `gheima` CLI from the checksummed release
binaries at [gheima/cli](https://github.com/gheima/cli/releases). It is the formula each
release attaches as `gheima.rb`; source lives in [gheima/gheima](https://github.com/gheima/gheima).
